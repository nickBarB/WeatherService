# WeatherService

Консольное приложение для получения погоды по координатам через API Яндекс Погоды.
Выводит полный JSON, текущую температуру и среднюю дневную температуру за выбранное число дней прогноза.

## Настройка

Нужны JDK 21, Maven и ключ API Яндекс Погоды с доступом к прогнозу.
Скопируйте `.env.example` в `.env` и укажите ключ:

```dotenv
YANDEX_WEATHER_API_KEY=ваш_ключ
```

`.env` исключён из Git. Переменная окружения с тем же именем имеет приоритет над файлом.

## Запуск

Из корня проекта:

```sh
mvn compile exec:java
```

В IDE запустите `Main.main` с корнем проекта в качестве рабочей директории.
Введите широту, долготу и количество дней прогноза.
